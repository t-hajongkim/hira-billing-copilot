GitHub 연결

깃헙은 익명 요청으로 워크플로를 시작해 주지 않습니다 — 공식 문서에 그렇게 적혀 있고, 페이지에서 바로 실행하려면 토큰이 한 번 필요합니다. 이 토큰은 이 브라우저에만 저장되고 페이지에도 저장소에도 들어가지 않습니다. 각자 자기 토큰으로 자기 저장소를 돌립니다.

이미 만들어 둔 토큰이 있으면 만들지 마세요 — 아래 칸에 붙여넣으면 됩니다. 깃헙은 한 번 만든 토큰 값을 다시 보여 주지 않으니, 어디에 적어 두지 않았다면 찾는 것보다 새로 만드는 쪽이 빠릅니다.

새로 만든다면 1 을 누르세요. 권한(repo)이 미리 체크된 발급 화면이 열립니다 → Generate token → 나온 값을 2 에 붙여넣으세요.

1 토큰 만들기 →
2

더 좁게 주려면 fine-grained token 에서 이 저장소만 고르고 Actions: Read and write 하나만 켜면 됩니다.
